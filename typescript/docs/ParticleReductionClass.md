
# ParticleReductionClass

The particle reduction class (Partikelminderungsklasse) according to \'Anlage XIV zu &sect; 48 StVZO\' (German law). This value is present for compatibility reasons and does not influence any of the results.  Supported for **engineType** _COMBUSTION_ and _HYBRID_.
